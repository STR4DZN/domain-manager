# Domain Manager — Auditoria Visual das Referências Sci‑Fi

Fonte: `Referencias Sci Fi.zip` (26 imagens). Esta auditoria trata cada arquivo individualmente; nenhuma imagem do ZIP foi omitida.

## Critérios usados
Para cada referência foram observados: composição/grid, navegação implícita, superfícies, tipografia, cor, geometria, visualização de dados, controles, estados, linguagem FUI, profundidade, microdetalhes, motion implícito, UX, aplicabilidade e risco.

## 01 — 001-Aftereefects assets FUI Illustrator Interface kit UI Unreal ux vector.webp
- **Composição:** coleção de módulos retangulares e instrumentos distribuídos em uma superfície escura, sem uma única tela dominante. O interesse vem da repetição disciplinada de molduras, barras, sliders e gauges.
- **Grid:** alinhamento modular muito forte, com blocos horizontais e verticais que parecem encaixar em um sistema comum.
- **Cor:** carvão/preto com âmbar, amarelo oliva e pequenas variações verdes. O acento ocupa pouca área e por isso continua legível.
- **Geometria:** cantos quase retos, pequenos recortes técnicos, linhas finas, hachuras diagonais e círculos concêntricos.
- **Tipografia:** compacta, técnica, majoritariamente caixa alta; números possuem mais peso visual que rótulos.
- **Dados/controles:** barras de capacidade, estados binários, pequenos controles circulares e gráficos compactos.
- **Motion implícito:** barras preenchendo, ticks de leitura, sweep circular; nada exige movimento contínuo.
- **Aplicação:** excelente base para **tokens, cards, resource rows, progress, health/state bars e instrumentação**.
- **Risco:** se todos os cards tiverem o mesmo nível de detalhe, o app perde hierarquia.
- **Relevância:** 9/10.

# Síntese do conjunto

## Família A — Command Amber
Referências: 01, 03, 08, 10, 14, 15, 18.

Direção: grafite quase preto + âmbar/laranja funcional + verde raro. É a família mais adequada para **shell, navegação, economia, projetos e estruturas**.

## Família B — Forensic Teal
Referências: 05, 12, 16, 19, 21, 22.

Direção: grayscale + verde/ciano, foco em identidade, vigilância, mapa, sinais e confirmação. É a família ideal para **People, Intel, Security e Mission Control**.

## Família C — Telemetry Red/Blue
Referências: 06, 13, 17, 20, 23, 24, 25, 26.

Direção: dashboards densos, telemetria e grande volume de informação. Deve inspirar **overview global e diagnostics**, sem contaminar todos os formulários.

## Família D — FUI Grammar
Referências: 02, 04, 09, 11.

Direção: primitives, glyphs, scales, connectors, corner cuts, waveforms, markers, noise e glitch. Serve como **vocabulário visual**, nunca como layout completo.

# Elementos aprovados para o Domain Manager
- Fundo grafite/navy quase preto, nunca preto puro em todas as camadas.
- Accent âmbar como identidade principal.
- Teal/verde para confirmação, inteligência e leitura de sistema.
- Vermelho reservado para risco/erro/colapso.
- Cyan/azul frio apenas para informação/telemetria.
- Painéis planos com bordas de 1px e recortes discretos.
- Tipografia técnica, mas legível; números grandes e labels menores.
- Grid modular denso, com hierarquia real de tamanho.
- IDs, timestamps e códigos como metadata contextual, não decoração aleatória.
- Micrográficos e gauges como informação real.
- Motion curto e orientado a estado.
- Glitch/scan apenas quando o significado justificar.

# Elementos rejeitados
- Glow permanente em todos os contornos.
- Scanline forte sobre texto.
- Boot cinematográfico obrigatório ao abrir o app.
- Animações infinitas puramente decorativas.
- Hexágonos usados sem função.
- Texto minúsculo falso para preencher espaço.
- Painéis com 4 ou 5 bordas internas sem hierarquia.
- HUD flutuante sem estrutura de aplicativo.
